# --- SIO domain terms that ste-lint reads as rotating synonyms ---
# `error` and `failure` are DISTINCT things here: `error_records` is a mined
# table, `log_failure` is the observability sink. Collapsing them would be
# wrong, so both are protected.
error
failure
# A "tool" is a harness tool call (tool_use / tool_result). A "script" is a
# file under scripts/. A "program" is neither. They are not interchangeable.
tool
script
# Click's own vocabulary: an `option` takes a value, a `flag` does not.
option
flag
# `config` is the ~/.sio/config.toml object; `settings` is not a SIO concept.
config
configuration

terminate
